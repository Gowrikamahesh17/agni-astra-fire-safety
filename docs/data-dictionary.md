# Data dictionary

Contract version 2.0. Generated by `data/` (`python -m ffd_data`). Schemas live in `contract/`.

All JSON files except models have the shape `{"contract_version": "2.0", "items": [...]}`. Any field may be `null` except ids.

## Units

| Quantity | Unit on the site | Conversion |
| --- | --- | --- |
| O2, CO2, He, N2 | % (mole or volume) | mole fraction x 100 |
| Pressure | bar | 1 mmHg = 0.00133322 bar, 1 psi = 0.0689476 bar |
| Lengths | mm | 1 in = 25.4 mm, 1 cm = 10 mm, 1 micron = 0.001 mm |
| Droplet burning rate | mm²/s | FLEX header says `mm`; the quantity is a burning-rate constant |

## observations.json

One entry per test row in the original CSVs.

| Field | Meaning |
| --- | --- |
| `id` | `<investigation>-<nnnn>`, numbered in file order. CFI-G numbers normal flames first, then inverse |
| `investigation_id` | PSI id, e.g. `PSI-69` |
| `flame_type` | CFI-G only: `normal` (fuel from burner into O2 atmosphere) or `inverse` (O2 from burner into fuel atmosphere) |
| `fuel`, `fuel_raw` | Lower-case fuel or material; `fuel_raw` keeps the original text |
| `fuel_fraction_pct` | CFI-G normal: from the fuel name (`30% butane` -> 30, pure gas -> 100). CFI-G inverse: `Xf before test` x 100. FLEX: 100 |
| `material` | Parsed solid material: PMMA, SIBAL, Nomex, Ultem, wax |
| `geometry` | `{shape, diameter_mm, thickness_mm, width_mm, raw}`. Shapes: rod, film, sheet, sphere, slab, fabric |
| `o2_pct`, `pressure_bar` | Test atmosphere before the test. Exception: in CFI-G inverse flames `o2_pct` is the oxidizer stream from the burner, not the chamber air (the chamber holds fuel) |
| `co2_pct`, `he_pct`, `n2_pct` | Diluents (FLEX). BASS-II `co2_pct` is the initial CO2 reading |
| `flow` | `{value, unit, kind}`. `velocity` (SAME-R, cm/s), `mass_flow` (CFI-G burner flow, mg/s), `device_setting` (BASS-II flow restrictor, not a velocity) |
| `gravity` | Always `micro`. PSI has no partial-gravity combustion data |
| `ignited` | `false` for CFI-G `no_ignition`, `true` for FLEX and ignited CFI-G rows, `null` where unknown |
| `outcome`, `outcome_raw` | Normalized label and original text (see below) |
| `censored` | `true` when the flame was stopped before it went out (burn time is a lower bound) |
| `measurements` | Per-table values, see below |
| `distance` | Distance to each preset scenario (see `docs/model-card.md`); `null` when O2 or pressure is missing |
| `source` | `{file, row}`. `row` is the 1-based line in the original CSV, header = row 1, counted before blank rows are dropped |

### Outcome labels

| Table | Raw | Label | Notes |
| --- | --- | --- | --- |
| FLEX | Extinction | `extinguished` | Flame went out with fuel left |
| FLEX | Disruption | `disrupted` | Droplet broke up or moved |
| FLEX | Completion | `burned_to_completion` | Droplet burned away |
| CFI-G | SE | `self_extinguished` | Flame went out by itself |
| CFI-G | FT | `sustained_until_stopped` | Flow termination: still burning when the flow was cut, the test timed out or the burner hit its temperature limit. `censored = true` |
| CFI-G | - | `no_ignition` | Burn time 0, `ignited = false` |

BASS-II, BASS and SAME-R have no outcome column, so `outcome` is `null`.

## Table notes

### FLEX (PSI-69)

- Columns `O`, `N`, `CO`, `He` are O2, N2, **CO2** and He. Subscripts were lost in the export. Confirmed against NASA's own report on these tests (NASA/TP-2015-216046, Appendix A, Table IX), whose column heading "Initial ambient composition, mole fraction" lists O2, N2, **CO2**, He, and whose first rows match this CSV (FLEX-001: 757.7 mmHg, 0.21 O2, 0.79 N2, droplet 1.69 mm, extinction diameter 0.89 mm, burning rate 0.52 mm2/s, burn time 4.3 s, Disruption). The PSI-69 web page itself could not be read automatically (it needs a browser).
- One row has pressure `0`; it is stored as `null` and left out of models and charts.
- Some cells contain a mis-encoded character (U+FFFD), mostly in the extinction diameter of disrupted tests. Stored as `null`.
- `Burn time` values like `~6` are stored as 6 with `measurements.burn_time_approx = true`.
- Measurements: `droplet_d0_mm`, `extinction_d_mm`, `burning_rate_mm2_s`, `burn_time_s`, `pressure_mmhg`, test number, identifier, date, GMT.

### CFI-G (PSI-159, ACME)

- Headers are normalized (extra spaces removed). O2: normal `XO2 before test`, inverse `XO2`.
- `Hot ignition` -> `measurements.hot_ignition` in `yes | no | flash`.
- `#DIV/0!` and `#VALUE!` spreadsheet errors are stored as `null`.
- Normal flames also keep `xf_burner` (the `Xf` column), which can differ from the fraction in the fuel name.
- Measurements: `burn_time_s`, `peak_burner_t_c`, `hot_ignition`, `tfp`, `adiabatic_flame_t_k`, `stoich_mixture_fraction`, `o2_after_pct` (normal), `xf_after_pct` (inverse), `fuel_flow_mg_s` / `fuel_burn_rate_mg_s`, `o2_flow_mg_s`, `color`, `cool_flame`, `comments`.

### BASS-II (PSI-25)

- No outcome and no flame-spread column: catalogue and viewer only, not modelled.
- No pressure column, so no scenario distance.
- Flow is a device setting (`Flow restrictor`); fan and air displays are kept as raw text.
- Unlabelled rods, films and slabs are PMMA (`measurements.material_inferred = true`).
- `none`, `OR`, `over`, `>500` become `null`; raw text is kept where useful (`co_final_raw`, `total_frames_raw`).

### BASS (PSI-26)

- Materials list only. Bare spheres are PMMA (`material_inferred = true`); candle and wax entries are `wax`.
- One row is `SOOT Cleaning`, not a burn; it is kept with `material = null`.

### SAME-R (PSI-101)

- Smoke sources only; detector results are not in the table. Detection findings come from cited text (`evidence_type: "text"`).
- `Description` variants are normalized (`w/aging` = `w/ aging`, case) and grouped into `measurements.run_type`.

## investigations.json

| Field | Meaning |
| --- | --- |
| `has_table`, `evidence_type` | `false` / `text` for metadata-only entries (Saffire, SAME, DAFT, other ACME) |
| `o2_pct_range`, `pressure_bar_range` | `[min, max]` over the investigation's rows |
| `scenario_components` | Per preset scenario: `proximity` (0-100), `n_near` (rows with d <= 1), `d_min` |
| `static_scores` | `fire_safety_relevance`, `data_usability` (see `docs/model-card.md`) |
| `doi` | PSI dataset DOI for the five table investigations; `null` for metadata-only entries |

## scenarios.json

Presets from the build spec. `assumption = true` marks presets we assumed (pressurized rover, Mars transit). `gravity_note` carries the partial-gravity warning for any scenario not in microgravity.
